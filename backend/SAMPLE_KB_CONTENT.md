# Sample Knowledge Base Content for IT Support

## Use these to test your chatbot:

### Content 1: Password Reset

**Title:** Password Reset Procedures
**Text:**
If you need to reset your password, please visit the employee portal at portal.company.com. Click on "Forgot Password" link and enter your email address. You will receive a password reset link within 5 minutes. If you don't receive the email, check your spam folder. The password must be at least 8 characters long and include uppercase, lowercase, numbers, and special characters. Passwords expire every 90 days for security purposes.

### Content 2: VPN Connection Issues

**Title:** VPN Troubleshooting Guide
**Text:**
When connecting to VPN fails, first check your internet connection. Make sure you're using the correct VPN server address: vpn.company.com. Try disconnecting and reconnecting. If the issue persists, clear your browser cache or restart the VPN client application. For Windows users, ensure the VPN service is running in Services. For Mac users, check System Preferences for VPN status. If you receive an authentication error, verify your username and password are correct. Contact IT support if problems continue after these steps.

### Content 3: Email Setup for Outlook

**Title:** Outlook Email Configuration
**Text:**
To set up Outlook email on your computer, open Outlook and select File > Add Account. Enter your full email address and password. For incoming mail server, use mail.company.com with port 993 for IMAP or 995 for POP3. For outgoing mail server, use smtp.company.com with port 587. Enable SSL/TLS encryption for both servers. Make sure "Remember password" is checked. If you encounter sync issues, go to Account Settings > Change and test the account settings. Outlook typically syncs every 30 minutes automatically.

### Content 4: Printer Troubleshooting

**Title:** Common Printer Problems and Solutions
**Text:**
If your printer is not responding, first check that it's turned on and connected to the network or computer. Verify the printer has paper and ink or toner. Try printing a test page from the printer's control panel. If printing fails, check if the printer appears in your computer's printer list. For network printers, ensure you're connected to the same Wi-Fi network. Clear any print queue errors in the printer settings. Restart the print spooler service if needed. For wireless printers, try reconnecting to the network. If the printer shows offline status, set it as default and check printer properties.

### Content 5: Software Installation Requests

**Title:** Requesting Software Installation
**Text:**
To request software installation, submit a ticket through the IT support portal with the software name, version, and business justification. Common approved software includes Microsoft Office Suite, Adobe Acrobat, and development tools like VS Code. Free software may require approval from your manager. Licensed software needs budget approval before installation. IT support will typically install software within 2 business days. Ensure you have administrator rights on your computer. Some software requires specific operating system versions - check compatibility before requesting.

### Content 6: Network Connection Issues

**Title:** Troubleshooting Network Connectivity
**Text:**
If you cannot connect to the internet or company network, check your network cable connection first. Ensure the cable is firmly plugged into both your computer and the network port or router. For wireless connections, verify you're connected to the correct Wi-Fi network. Try forgetting and reconnecting to the network. Restart your network adapter in Device Manager. Run network diagnostics by right-clicking the network icon and selecting "Troubleshoot problems". Check if other devices on the same network are working. If you're using a VPN, disconnect it temporarily to test basic connectivity. Contact IT if the issue affects multiple devices or persists after troubleshooting.

### Content 7: Laptop Performance Issues

**Title:** Improving Laptop Performance
**Text:**
If your laptop is running slowly, first restart it to clear temporary files. Check available disk space - ensure at least 10% of your hard drive is free. Close unnecessary applications and browser tabs. Run disk cleanup utility to remove temporary files. Check Task Manager for programs using high CPU or memory. Uninstall unused applications. Update your operating system and drivers. Disable startup programs that you don't need. Increase virtual memory if you have low RAM. Consider adding more RAM if problems persist. For persistent slowness, contact IT support for a hardware check or reimage.

### Content 8: Two-Factor Authentication Setup

**Title:** Two-Factor Authentication (2FA) Setup
**Text:**
Two-factor authentication adds an extra layer of security to your accounts. To enable 2FA, log into the employee portal and go to Security Settings. Select "Enable Two-Factor Authentication". You'll need to download an authenticator app like Google Authenticator or Microsoft Authenticator on your phone. Scan the QR code displayed on screen with your authenticator app. Enter the 6-digit code from the app to verify. Save backup codes in a secure location in case you lose access to your phone. You'll need to enter a code from the app every time you log in from a new device. If you lose your phone, contact IT support immediately to reset 2FA using backup codes.

### Content 9: WiFi Connection Problems

**Title:** WiFi Connection Troubleshooting
**Text:**
If you're having trouble connecting to WiFi, first check if you're connected to the correct network. Look for networks named "CompanyWiFi" or "CorpNet". If you don't see the network, move closer to the access point or try a different location. Forgetting and reconnecting to the network often helps. Go to Settings > Network & Internet > WiFi, click on the network name, and select "Forget". Then search for the network again and enter the password when prompted. If you're still having issues, try restarting your computer. For persistent problems, check if other devices can connect to the same network. If the WiFi works on other devices but not yours, the issue might be with your device settings.

### Content 10: Login Issues (Beyond Password)

**Title:** Login Problems and Account Access
**Text:**
If you're having trouble logging in beyond just forgetting your password, first check if Caps Lock is on. Make sure you're using the correct username format - usually your email address or "firstname.lastname". If you get an "account locked" message, wait 15 minutes and try again, or contact IT support to unlock it. Check if your account has expired or been disabled. For domain login issues, ensure you're connected to the company network or VPN. If you see "invalid credentials" but you're sure the password is correct, your account might have been reset or changed. Try logging in from a different device to isolate the issue. If the problem persists across devices, there might be an account configuration issue that IT needs to resolve.

### Content 11: Microsoft Word Issues

**Title:** Microsoft Word Troubleshooting
**Text:**
If Microsoft Word is not working properly, first try restarting the application. If Word crashes on startup, try opening it in Safe Mode by holding Ctrl while clicking the Word icon. Check if your document is corrupted by opening a new blank document. If Word opens but you can't type, check if the document is protected or if you're in a read-only mode. For formatting issues, try clearing formatting with Ctrl+Spacebar. If Word is running slowly, close other applications and check available memory. Update Office to the latest version through File > Account > Update Options. If you can't save documents, check if the file is open by another user or if you have write permissions to the folder. For persistent crashes, repair Office installation through Control Panel > Programs > Modify.

### Content 12: File Access Problems

**Title:** File and Folder Access Issues
**Text:**
If you can't access files or folders, first check if the file exists and you're looking in the right location. Verify you have the correct permissions by right-clicking the file/folder and selecting Properties > Security. If you see "access denied", you might not have the right permissions. Try accessing the file from a different location or ask the file owner to grant you access. For network drives, ensure you're connected to the company network or VPN. If files are opening as read-only, check if they're checked out in SharePoint or if another user has them open. For shared drives, make sure the drive is mapped correctly. If you can access some files but not others, it might be a permissions issue on specific folders. Contact IT support if you need elevated permissions or if the issue affects multiple files.

### Content 13: Remote Desktop Setup

**Title:** Remote Desktop Connection Setup
**Text:**
To set up Remote Desktop for working from home, first ensure Remote Desktop is enabled on your office computer. Go to Settings > System > Remote Desktop and turn it on. Note the computer name shown there. On your home computer, search for "Remote Desktop Connection" and open it. Enter the office computer name or IP address. When prompted, enter your work username and password. For better security, use VPN first before connecting. If you get connection errors, check firewall settings and ensure port 3389 is open. For Mac users, download Microsoft Remote Desktop from the App Store. Save your connection settings for easy access later. If you have multiple monitors, you can configure Remote Desktop to use all monitors. For slow connections, reduce color depth and screen resolution in the connection settings.

### Content 14: Antivirus Software Issues

**Title:** Antivirus and Security Software Problems
**Text:**
If antivirus software is causing issues, first check if it's up to date. Open the antivirus program and look for update options. If scans are running slowly, schedule them for off-hours. If the antivirus is blocking legitimate programs, add them to the exclusion list. For Windows Defender, go to Settings > Update & Security > Windows Security > Virus & threat protection > Manage settings > Exclusions. If you're getting false positive alerts, report them to IT support. Don't disable antivirus unless instructed by IT. If the antivirus is preventing system updates, temporarily disable real-time protection during updates. For conflicting security software, uninstall one of them as running multiple antivirus programs can cause conflicts. If scans are failing, check disk space and run a disk cleanup first.

### Content 15: Mobile Device Setup

**Title:** Mobile Device Configuration for Work
**Text:**
To set up your mobile device for work email and apps, first download the company email app or configure the built-in mail app. For Exchange email, use the server address provided by IT. Enable two-factor authentication if required. Install company-approved apps from the app store. For WiFi access, connect to the guest network first, then request corporate WiFi access from IT. Set up VPN if required for secure access. Configure screen lock with PIN or biometric. Enable remote wipe capability through company portal app. For iOS devices, download Company Portal from App Store. For Android, download from Google Play Store. Register your device with IT for management. Set up backup to iCloud or Google Drive. If you lose your device, contact IT immediately to remotely wipe it.

### Content 16: Browser Issues

**Title:** Web Browser Troubleshooting
**Text:**
If your web browser is not working properly, first try clearing cache and cookies. In Chrome, go to Settings > Privacy and security > Clear browsing data. In Firefox, go to Settings > Privacy & Security > Cookies and Site Data > Clear Data. If websites won't load, check your internet connection. Try a different browser to isolate the issue. Disable browser extensions one by one to find conflicts. Reset browser settings to default if problems persist. Update your browser to the latest version. Check if JavaScript is enabled in browser settings. For SSL certificate errors, check your system date and time. If you're behind a proxy, ensure proxy settings are correct. For corporate websites, you might need to be on VPN. Clear DNS cache by running "ipconfig /flushdns" in Command Prompt.

### Content 17: USB Device Problems

**Title:** USB Device Connection Issues
**Text:**
If USB devices aren't working, first try different USB ports on your computer. Some ports might provide more power than others. Check if the device requires drivers - look in Device Manager for yellow exclamation marks. Try the device on a different computer to isolate the issue. For USB drives, check if they're formatted correctly and not corrupted. Safely eject USB devices before removing them. If devices disconnect randomly, check for loose connections or damaged cables. Update USB drivers through Device Manager. For USB 3.0 devices, ensure you're using USB 3.0 ports (usually blue). If multiple devices aren't working, try a powered USB hub. Check power management settings - some computers turn off USB ports to save power. Disable USB selective suspend in Power Options > Change plan settings > Change advanced power settings.

### Content 18: Screen and Monitor Issues

**Title:** Display and Monitor Troubleshooting
**Text:**
If your screen or monitor has issues, first check cable connections. Ensure the cable is securely plugged into both the monitor and computer. Try a different cable or port. Adjust brightness and contrast using monitor buttons. For multiple monitors, right-click desktop and select Display settings to arrange them. If the screen is flickering, check refresh rate settings. Update graphics drivers from the manufacturer's website. For resolution issues, set to recommended resolution in Display settings. If colors look wrong, calibrate the monitor or reset color settings. For laptop screens, check if external monitor works - if it does, the issue is with the laptop screen. Clean the screen with a microfiber cloth. If the screen is cracked or has dead pixels, contact IT for replacement. For brightness that won't adjust, check keyboard shortcuts and power settings.

### Content 19: Keyboard and Mouse Problems

**Title:** Keyboard and Mouse Troubleshooting
**Text:**
If your keyboard or mouse isn't working, first check the connections. For wireless devices, ensure batteries are charged and the receiver is plugged in. Try different USB ports. Clean the devices - keyboards can be cleaned with compressed air, mice with a soft cloth. Check if the devices work on another computer. Update drivers through Device Manager. For Bluetooth devices, ensure Bluetooth is enabled and devices are paired correctly. If keys are sticking, the keyboard might need cleaning or replacement. For erratic mouse movement, check the mouse pad surface and clean the optical sensor. Test with on-screen keyboard if physical keyboard fails. For programmable keyboards/mice, reset to factory defaults. Check if the devices are disabled in Device Manager. If multiple USB devices fail, the issue might be with USB ports or drivers.

### Content 20: Application Crashes

**Title:** Application Crash Troubleshooting
**Text:**
When applications crash, first check if the program is up to date. Restart the application and try again. If it crashes on startup, try running as administrator. Check system requirements - ensure your computer meets minimum specs. Update Windows and drivers. Run the program in compatibility mode for older software. Check Event Viewer for error details. Disable antivirus temporarily to see if it's interfering. Repair the application through Control Panel > Programs > Modify. If it's a Microsoft app, run Office Repair. Clear temporary files and check disk space. Run System File Checker with "sfc /scannow" command. If the crash happens with specific files, those files might be corrupted. Try opening the application in Safe Mode or with minimal extensions. For persistent crashes, reinstall the application or contact the software vendor.

### Content 21: Windows Update Issues

**Title:** Windows Update Troubleshooting
**Text:**
If Windows updates are failing, first check your internet connection. Ensure you have enough disk space - updates need at least 10GB free. Run Windows Update Troubleshooter from Settings > Update & Security > Troubleshoot. Restart the Windows Update service through services.msc. Clear the SoftwareDistribution folder by stopping the service, renaming the folder, and restarting. Check if you're on a metered connection - updates might be paused. Temporarily disable third-party antivirus. Ensure your Windows license is activated. For feature updates, check if your hardware meets requirements. If updates install but fail to apply, boot into Safe Mode and try again. Use Media Creation Tool for major version updates. Check Windows Update error codes online for specific solutions. If all else fails, clean install Windows or contact IT support.

### Content 22: Backup and Restore

**Title:** Data Backup and Restore Procedures
**Text:**
For data backup, use the built-in Windows Backup or third-party tools approved by IT. Go to Settings > Update & Security > Backup to set up automatic backups. Choose what to back up - documents, pictures, and important files. Select backup location - external drive or network location. Schedule regular backups. For OneDrive, files are automatically backed up if enabled. To restore files, go to the backup location and copy files back. For system restore, go to Settings > Update & Security > Recovery > Go back to the previous version of Windows. For file recovery, use Previous Versions by right-clicking files. If you need to restore from IT backup, contact support with the date and files needed. Always verify backups by testing restore occasionally. Keep multiple backup copies in different locations for redundancy.

### Content 23: Microsoft Teams Setup

**Title:** Microsoft Teams Configuration
**Text:**
To set up Microsoft Teams, download it from teams.microsoft.com or Microsoft Store. Sign in with your work email. If prompted, join your organization. Configure audio and video settings by clicking your profile picture > Settings > Devices. Test microphone and speakers. For meetings, ensure camera permissions are granted. Set status appropriately - Available, Busy, Away, etc. Customize notifications in Settings > Notifications. For chat, you can create channels and add team members. Share screens by clicking Share in meetings. Record meetings if needed (check if your organization allows it). Use @mentions to get someone's attention. For troubleshooting, clear Teams cache by holding Ctrl+Shift+Alt+1 (or Command on Mac). Update Teams to the latest version. If you can't sign in, check if your account is licensed for Teams.

### Content 24: Excel Issues

**Title:** Microsoft Excel Troubleshooting
**Text:**
If Excel is not working properly, first try opening a new workbook to isolate the issue. If Excel opens but files won't load, the files might be corrupted. Try opening in Safe Mode by holding Ctrl while opening Excel. Check file associations - right-click an Excel file and select Open with > Choose another app > Excel. For calculation errors, check if manual calculation is enabled (Formulas tab > Calculation Options). If Excel is slow, disable add-ins through File > Options > Add-Ins > Manage > COM Add-ins. Update Excel through File > Account > Update Options. For formula errors, check cell references and syntax. If charts aren't displaying, check if data source is correct. Repair Office installation if problems persist. For large files, increase memory or split into smaller files. Check Excel version compatibility when sharing files.

### Content 25: PowerPoint Problems

**Title:** Microsoft PowerPoint Troubleshooting
**Text:**
If PowerPoint presentations aren't working, first check if the file is corrupted by creating a new presentation. Try opening PowerPoint in Safe Mode. Ensure you have the correct version of PowerPoint for the file. For display issues, check screen resolution and zoom settings. If animations aren't working, check if they're enabled in Slide Show > Set Up Slide Show. Update PowerPoint through File > Account. For embedding issues, ensure linked files are accessible. If presentations are slow, reduce image sizes and compress media. Check font availability - missing fonts can cause display issues. For presenter view problems, ensure multiple monitors are set up correctly. Repair Office installation for persistent issues. Save presentations in different formats to test. Use PowerPoint Online if desktop version fails. Check file permissions if you can't save or open presentations.
